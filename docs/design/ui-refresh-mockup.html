Technical detail

Shift sizes use the population stability index: below 0.10 little, 0.10–0.25 moderate, above 0.25 large. These are common conventions, not pass or fail limits. Fixed deposit rate shift: 0.024 mild, 0.326 severe. KS distance on scores: 0.001 mild, 0.007 severe, shown without p-values because each scenario is a paired copy of the same customers. The weighted deposit rate is blank for customers with no deposit, so it is compared on 384 customers against 376 (mild) and 344 (severe).

Performance not evaluated: hypothetical outcomes are unavailable.

This scenario changes deposit-related inputs only. Transaction activity, digital engagement and service-friction inputs are held constant, and scenario-specific explanations are not computed. Competitor pass-through is context only; exit shares are separate assumptions, not responses calculated from the rate gap.
